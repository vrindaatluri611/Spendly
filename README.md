# Spendly — Finance Tracking UI

A front-end-only prototype for the Spendly finance tracking project.

## What is included
- Dashboard with spending overview, category budgets, recent transactions and alerts
- Expense tracking UI with search and add-expense demo
- Budget monitoring UI
- Bill splitting UI
- Lending & borrowing UI
- Bank statement upload placeholder
- Parent control UI
- Settings UI
- Responsive design for desktop and mobile
- Green + gold finance-inspired visual theme

## Current scope
This is intentionally a UI/UX prototype (~50% of the project). It uses mock data and browser-side JavaScript only.

### Not connected yet
- Java backend
- MySQL/database
- Authentication
- Real bank statement parsing
- Real payment/bank integration
- Real parental transaction blocking

## Run locally
No installation is required.

Option 1: Double-click `index.html`.

Option 2: Use VS Code + Live Server:
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` → **Open with Live Server**.

## Suggested next phase
Connect the existing screens to your Java backend using REST APIs. Then connect MySQL for users, transactions, budgets, groups, settlements, and lending records.
